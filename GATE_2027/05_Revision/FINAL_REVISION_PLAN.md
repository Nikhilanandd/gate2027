## Revision Strategy

### 1. Formula Sheets
- Create ONE page per subject with all formulas, key theorems, and shortcuts
- Laminate or use plastic sleeves for protection
- Review daily — spend 20 min each morning going through all sheets
- Update as you find gaps during mocks

### 2. PYQ Revision Cycle
- **First pass (Nov–Dec):** Topic-wise, solve all PYQs from 2000–2026
- **Second pass (Jan):** Year-wise, solve last 5 years (2022–2026)
- **Third pass (Feb):** Only questions you got wrong previously

### 3. Mock Test Analysis (Most Important)
For EVERY mock test:
1. Note your score and time taken
2. Mark every question: Correct (C), Wrong (W), Skipped (S)
3. For wrong answers: Find why — silly mistake (SM), conceptual gap (CG), time pressure (TP)
4. Update error log with category
5. Revise the concept for CG errors immediately
6. **Target pattern:** Reduce SM to 0, reduce CG over time

### 4. Error Log Review
- Maintain a notebook or spreadsheet with columns: Date, Mock, Question, Error Type, Correct Approach
- Review entire log every Sunday
- Before final exam week, review all entries — this is your personal weak area map

## Exam Day Strategy

### Time Allocation (3 hours = 180 minutes)

| Phase | Time | Activity |
|-------|------|----------|
| **Phase 1** | 0–30 min (30 min) | Scan all 65 questions. Mark: Easy (E), Medium (M), Hard (H). Identify sure-shot questions. |
| **Phase 2** | 30–120 min (90 min) | Solve all E questions first, then M. Don't get stuck — skip if >3 min. |
| **Phase 3** | 120–170 min (50 min) | Attempt remaining H questions. Apply elimination, educated guessing. |
| **Phase 4** | 170–180 min (10 min) | Review marked answers. Fill any unanswered NAT. Verify MSQ selections. |

### Question Type Strategy

| Type | Strategy |
|------|----------|
| **MCQ (1 mark)** | Quick solve, 1 min target. Don't overthink. |
| **MCQ (2 marks)** | 2–3 min target. Use elimination. |
| **MSQ (Multiple Select)** | **Only attempt if 100% sure.** No negative marking, but wrong = 0. Partial correct = marks. If confident on 2 of 4 options, marking all correct earns full marks. |
| **NAT (Numerical)** | **Attempt ALL you can solve.** No negative marking. Even rough calculations can get you marks. |

### Negative Marking Rules
- MCQ (1 mark): −1/3 for wrong
- MCQ (2 marks): −2/3 for wrong
- MSQ: No negative marking (0 for wrong)
- NAT: No negative marking (0 for wrong)

> **Key insight:** NAT and MSQ have no penalty. Attempt every NAT you can solve. For MSQ, only mark answers you're confident about.

### Mental Framework
1. **Don't panic** if you see tough questions early — they're distributed randomly
2. **Don't compare** with other candidates during exam week
3. **Trust your preparation** — you've done 5 months of work
4. **One question at a time** — focus only on the current problem
5. **If stuck for >3 min, skip** — come back later if time permits
