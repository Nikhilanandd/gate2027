6. **Binary Heaps** — Min heap, max heap, heap operations, heap sort
7. **Graphs** — Representation (adjacency matrix, adjacency list), BFS, DFS

## Key Concepts to Master

### C Programming Tricky Concepts
```c
// Pointer-Array Equivalence
int a[5] = {10, 20, 30, 40, 50};
int *p = a;
// a[i] ≡ *(a+i) ≡ *(p+i) ≡ p[i]

// Pointer Arithmetic
p + 1  // Advances by sizeof(int) bytes
(p+1)  // Points to next element, NOT next byte

// Static Variable in Recursion
int fun() {
    static int x = 0;
    x++;
    return x;
}
// Each call preserves x's value

// Conditional Operator
(a > b) ? a : b  // Returns max(a, b)

// Operator Precedence (High to Low)
// () [] -> . (highest)
// ++ -- (prefix) ! ~ (type) sizeof * & (unary)
// * / %
// + -
// << >>
// < <= > >=
// == !=
// & ^ |
// && ||
// ?: (ternary)
// = += -= (assignment) (lowest)
```

### Data Structure Time Complexities
```
Operation          | Array | Stack | Queue | LinkedList | BST (avg) | Heap
-------------------|-------|-------|-------|------------|-----------|------
Insert (end)       | O(1)* | O(1)  | O(1)  | O(1)       | O(log n)  | O(log n)
Insert (begin)     | O(n)  | N/A   | N/A   | O(1)       | O(log n)  | O(log n)
Delete (end)       | O(1)* | O(1)  | O(1)  | O(n)       | O(log n)  | O(log n)
Delete (begin)     | O(n)  | N/A   | O(1)  | O(1)       | O(log n)  | O(log n)
Search             | O(n)  | O(n)  | O(n)  | O(n)       | O(log n)  | O(n)
Access by index    | O(1)  | N/A   | N/A   | O(n)       | O(log n)  | O(n)

* amortized
```

### BST Properties
```
Inorder traversal → sorted sequence
Minimum element → leftmost node
Maximum element → rightmost node
Height balanced BST (AVL) → |height(left) - height(right)| ≤ 1 for all nodes
Number of BSTs with n nodes = Catalan number C(n) = C(2n,n)/(n+1)
```

### Heap Properties
```
Min Heap: parent ≤ children → minimum at root
Max Heap: parent ≥ children → maximum at root

Heapify: O(log n) — fix one violation by bubbling down
Build Heap: O(n) — start from last non-leaf, heapify each
Insert: O(log n) — add at end, bubble up
Delete-min: O(log n) — replace root with last, heapify

Binary Heap as Array:
  Parent of i: (i-1)/2
  Left child of i: 2i+1
  Right child of i: 2i+2
```

### Recursion Patterns
```
Base Case: when to stop recursion
Recursive Case: how to reduce problem size
Tail Recursion: recursive call is last operation (can be optimized to loop)
Recursion Tree: visualize to count calls and operations

Common patterns:
  factorial(n) = n × factorial(n-1)
  fib(n) = fib(n-1) + fib(n-2) — O(2^n) without memoization
  tower_of_hanoi(n) = 2^n - 1 moves
```

## Common Mistake Patterns

| Mistake | How to Avoid |
|---------|--------------|
| Pointer dereference without initialization | Always check *p is valid before use |
| Array index out of bounds | Array indices: 0 to n-1, not 1 to n |
| Forgetting malloc return value check | Handle NULL return from malloc |
| Static variable in recursion confusion | Static retains value across calls |
| BST validation failure | Inorder must be strictly increasing |
| Heap property violation after insert/delete | Always bubble up/down correctly |
| Linked list cycle detection error | Use Floyd's tortoise and hare |
| Off-by-one in loop conditions | Check < vs <= carefully |
| Confusing = (assignment) with == (comparison) | Use (0 == x) style if prone to error |
| Memory leak in linked list | Free all nodes in reverse order |
