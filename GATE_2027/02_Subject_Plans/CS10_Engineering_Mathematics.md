## GATE 2027 Syllabus

### Discrete Mathematics (Primary Focus)
1. **Propositional Logic** — Logical connectives, truth tables, equivalences, normal forms (CNF, DNF), satisfiability
2. **First Order Logic** — Predicates, quantifiers (forall, exists), logical equivalence, prenex normal form
3. **Sets, Relations, Functions** — Set operations, relations (reflexive, symmetric, antisymmetric, transitive, equivalence, partial order), functions (injective, surjective, bijective), composition, inverse
4. **Partial Orders and Lattices** — Hasse diagrams, maximal/minimal elements, chains, antichains, lattice properties
5. **Combinatorics** — Counting (permutations, combinations), pigeonhole principle, inclusion-exclusion, recurrence relations, generating functions
6. **Graph Theory** — Types (directed, undirected, weighted, bipartite, planar, complete, tree), degree, paths, cycles, Euler circuit, Hamiltonian cycle, graph coloring, matching, connectivity
7. **Algebraic Structures** — Monoids, groups (properties, subgroups, cyclic groups, Lagrange theorem), rings (basic)

### Linear Algebra
8. **Matrices** — Types (symmetric, skew-symmetric, orthogonal), operations, transpose, inverse, rank
9. **Determinants** — Properties, cofactor expansion, Cramer rule
10. **Systems of Linear Equations** — Consistent/inconsistent, Gaussian elimination, rank method
11. **Eigenvalues and Eigenvectors** — Characteristic equation, diagonalization, Cayley-Hamilton theorem
12. **LU Decomposition**

### Calculus
13. **Limits** — L'Hopital rule, standard limits
14. **Continuity** — Types of discontinuity
15. **Differentiability** — Chain rule, implicit differentiation
16. **Maxima and Minima** — First/second derivative test, optimization
17. **Mean Value Theorems** — Rolle, Lagrange, Cauchy
18. **Integration** — Definite integrals, properties, fundamental theorem of calculus
19. **Multiple Integrals** — Double integrals (basics)

### Probability
20. **Random Variables** — Discrete and continuous, PMF, PDF, CDF
21. **Distributions** — Binomial, Poisson, Uniform, Exponential, Normal
22. **Expectation and Variance** — E(X), Var(X), standard deviation
23. **Bayes Theorem** — Conditional probability, prior/posterior
24. **Conditional Probability** — P(A|B), independence, multiplication rule

## Key Formulas and Concepts to Master

### Propositional Logic

```
Logical Equivalences:
  Commutative: p ^ q = q ^ p
  Associative: (p ^ q) ^ r = p ^ (q ^ r)
  Distributive: p ^ (q v r) = (p ^ q) v (p ^ r)
  De Morgan's: ~(p ^ q) = ~p v ~q
  Implication: p -> q = ~p v q
  Contrapositive: p -> q = ~q -> ~p
  Double Negation: ~~p = p
  Absorption: p v (p ^ q) = p

Normal Forms:
  CNF: conjunction of clauses, each clause is disjunction of literals
  DNF: disjunction of clauses, each clause is conjunction of literals
  To convert: use truth table, pick rows where result is true, construct DNF/CNF
```

### First Order Logic

```
Translation patterns:
  "All A are B": Ax(A(x) -> B(x))
  "Some A are B": Ex(A(x) ^ B(x))
  "No A are B": Ax(A(x) -> ~B(x)) or ~Ex(A(x) ^ B(x))
  "Some A are not B": Ex(A(x) ^ ~B(x))

Prenex Normal Form: all quantifiers at the front
```

### Combinatorics

```
Permutations: P(n,r) = n!/(n-r)!
Combinations: C(n,r) = n!/(r!(n-r)!)
Pigeonhole: if n items in m containers, one container has >= ceil(n/m) items

Inclusion-Exclusion:
  |A U B| = |A| + |B| - |A n B|
  |A U B U C| = |A|+|B|+|C| - |AnB|-|AnC|-|BnC| + |AnBnC|

Recurrence Relations:
  Linear homogeneous: an = c1*an-1 + c2*an-2
  Characteristic equation: x^2 - c1*x - c2 = 0
  If roots r1, r2: an = alpha*r1^n + beta*r2^n
  Use initial conditions to find alpha, beta

Generating Function: G(x) = sum(an * x^n)
  (1-x)^-1 = 1 + x + x^2 + ...
  (1-x)^-2 = 1 + 2x + 3x^2 + ...
```

### Graph Theory

```
Degree: deg(v) = number of edges incident to v
Handshaking Lemma: sum(deg(v)) = 2|E|

Euler Circuit: exists iff connected and all vertices have even degree
Euler Path: exists iff connected and exactly 0 or 2 vertices have odd degree
Hamiltonian Cycle: NP-complete to decide, no simple characterization

Planar Graph: can be drawn without edge crossings
Euler's Formula: V - E + F = 2 (for connected planar graph)
For planar graph: E <= 3V - 6

Graph Coloring: minimum colors for proper coloring = chromatic number chi(G)
Bipartite: 2-colorable iff no odd cycle
Complete graph Kn: chi(Kn) = n
Tree: chi(tree) = 2 (if >= 1 edge)

Bipartite Matching:
  Konig Theorem: in bipartite graph, size of max matching = size of min vertex cover
```

### Groups and Algebraic Structures

```
Group: (G, *) is group if:
  1. Closure: a*b in G for all a,b in G
  2. Associativity: (a*b)*c = a*(b*c)
  3. Identity: exists e such that a*e = e*a = a
  4. Inverse: for each a, exists a' such that a*a' = e

Abelian Group: additionally commutative (a*b = b*a)
Subgroup: H subset G, (H,*) is also a group
Cyclic Group: exists g such that every element = g^n for some n

Lagrange Theorem: |H| divides |G| for subgroup H of G
  Corollary: order of element divides |G|

Monoid: closure + associativity + identity (no inverse required)
Semigroup: closure + associativity (no identity, no inverse)
```

### Linear Algebra

```
Determinant Properties:
  det(AB) = det(A) * det(B)
  det(A^T) = det(A)
  det(kA) = k^n * det(A) (for n x n matrix)
  det(A) = 0 iff A is singular (non-invertible)

Inverse: A^-1 = adj(A) / det(A)

Rank: number of linearly independent rows/columns
  rank(A) = rank(A^T)
  rank(AB) <= min(rank(A), rank(B))

Eigenvalues: det(A - lambda*I) = 0
Eigenvectors: (A - lambda*I)x = 0

Cayley-Hamilton Theorem: every square matrix satisfies its own characteristic equation
  If p(lambda) = det(A - lambda*I), then p(A) = 0

Diagonalization: A = PDP^-1 where D = diagonal matrix of eigenvalues
  A is diagonalizable iff it has n linearly independent eigenvectors

LU Decomposition: A = LU where L = lower triangular, U = upper triangular
  Used for solving Ax = b efficiently
```

### Calculus

```
L'Hopital Rule: lim f(x)/g(x) = lim f'(x)/g'(x) when 0/0 or inf/inf

Mean Value Theorem:
  Rolle: if f(a)=f(b), exists c in (a,b) such that f'(c)=0
  Lagrange: exists c in (a,b) such that f'(c) = (f(b)-f(a))/(b-a)

Maxima/Minima:
  First derivative test: sign change of f'(x) at critical point
  Second derivative test: f''(c) < 0 => max, f''(c) > 0 => min

Fundamental Theorem of Calculus:
  d/dx integral(a to x) f(t)dt = f(x)
  integral(a to b) f(x)dx = F(b) - F(a) where F'(x) = f(x)
```

### Probability

```
Conditional Probability: P(A|B) = P(AnB) / P(B)

Bayes Theorem:
  P(Ai|B) = P(B|Ai) * P(Ai) / sum(P(B|Aj) * P(Aj))

Independence: P(AnB) = P(A) * P(B)

Distributions:
  Binomial: P(X=k) = C(n,k) * p^k * (1-p)^(n-k), E=np, Var=np(1-p)
  Poisson: P(X=k) = (lambda^k * e^-lambda) / k!, E=Var=lambda
  Uniform(a,b): f(x) = 1/(b-a), E=(a+b)/2, Var=(b-a)^2/12
  Exponential: f(x) = lambda*e^(-lambda*x), E=1/lambda, Var=1/lambda^2
  Normal: f(x) = (1/sqrt(2pi*sigma^2)) * e^(-(x-mu)^2/(2*sigma^2))

Expectation Properties:
  E(aX+b) = aE(X)+b
  Var(X) = E(X^2) - (E(X))^2
  Var(aX+b) = a^2 * Var(X)
```

## Common Mistake Patterns

| Mistake | How to Avoid |
|---------|--------------|
| Wrong truth table for implication | p -> q is false ONLY when p is true and q is false |
| Pigeonhole off-by-one | Use ceiling, not floor: ceil(n/m) |
| Euler vs Hamiltonian confusion | Euler = visits every EDGE once; Hamiltonian = visits every VERTEX once |
| Bayes theorem order error | P(A|B) = P(B|A)*P(A)/P(B), not P(A|B) = P(A)*P(B)/P(B) |
| Eigenvalue characteristic equation error | Always compute det(A - lambda*I), not det(A) - lambda |
| Recurrence root multiplicity error | If repeated root r: solution has (alpha + beta*n)*r^n |
| Graph coloring lower bound | chi(G) >= max(clique number, ceil(V/delta+1)) |
| Determinant sign errors | Sign = (-1)^(i+j) for cofactor at position (i,j) |
| Union-find rank mistake | Always attach smaller tree under larger tree |
| Group order of element error | Order of a = smallest n such that a^n = e |
